# Security policy

VaderHaptics controls local controller visibility and motor output. Report
issues that could leave a device hidden, bypass recovery, unexpectedly activate
motors, expose personal paths/data, or weaken game protections privately to the
maintainer listed by the future GitHub repository.

Do not include controller serials, full hardware paths, game captures, or
credentials in a public report. This project will not accept anti-cheat bypass,
injection, or protected-game evasion work.
